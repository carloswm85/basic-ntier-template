# Scaling Up: From Identity API to Identity Server

## Progressive Path

### 1. Starting Point

Identity API implementations:

- Using Web API:
  - Default ASP\.NET Core endpoints: Cookies and OAuth2 Tokens (also known as _opaque tokes_)
  - Custom endpoints: JWS
- Using MVC:
  - Default ASP\.NET Core implementation

### 2. Scaling Up Alternatives

Identity API to can be scaled up to:

| Server          | Link                                                           | Standards            |
| --------------- | -------------------------------------------------------------- | --------------------- |
| IndentityServer | [Docs](https://duendesoftware.com/products/identityserver)     | OpenID Connect (OIDC) |
| OpenIddict      | [Docs](https://documentation.openiddict.com/guides/index.html) | ?                     |

### 3.1 Implementation

| Authentication | Cookies | Bearer Tokens (a) | JWT Tokens |

### Note on Tokens

> In particular, the Identity API endpoints are not intended to replace your IdentityServer or OpenIddict token servers. The access tokens generated by the Identity endpoint are intended to be used by that app and that app only. Also, they're intended to be used by interactive users, not for machine-to-machine communication.
